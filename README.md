# FutureFactor360 Tools

Landing page that links to every FutureFactor360 proprietary tool and demo.

Live: https://aiuserff360.github.io/futurefactor-tools/

## Adding a demo

Edit `tools.js`, copy an existing entry and change its fields (name, tagline, description, url, category, status, signIn, highlights, updated). Commit and push to `main`; GitHub Pages republishes the page within a minute or two.

No build step. The site is plain HTML, CSS and JavaScript.
